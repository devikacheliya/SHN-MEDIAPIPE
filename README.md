#  AgriVision: Produce Ripeness & Defect Grader

### 💡 What's the idea?
An automated computer vision tool that uses a webcam feed to inspect produce (like tomatoes or apples), measure their size in millimeters, detect surface defects, and grade their quality in real time.

### 🌐 Check it out!
- **GitHub Repo:** https://github.com/devikacheliya/SHN-MEDIAPIPE/tree/main

### 🛠️ What did you use?
Python 3.12, OpenCV (cv2), NumPy, MediaPipe Tasks API, VS Code, PowerShell

### ✨ Cool Things It Does

-Real-time HSV color masking to calculate green vs. red produce ripeness ratios

-Bounding contour extraction (cv2.contourArea) to estimate fruit diameter in millimeters

-Automated quality control logic that overlays live badges ("Grade A", "Grade B", "Reject") on video feed based on defect percentages
